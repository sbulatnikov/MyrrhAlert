# MyrrhAlert

Аддон для Аллодов Онлайн: предупреждает надписью вверху экрана, когда у персонажа заканчивается запас.

| Что считаем | Где | Надпись |
|---|---|---|
| мирра | ценности | «НЕДОСТАТОЧНО МИРРЫ» |
| мана-батареи | сумка, все стопки вместе | «НЕДОСТАТОЧНО МАНА-БАТАРЕЙ» |
| модули памяти | ценности | «НЕДОСТАТОЧНО МОДУЛЕЙ ПАМЯТИ» |

- `/myrrh` — окно настроек: у каждого запаса свой порог и текущее количество. Порог 0 — не предупреждать.
  По умолчанию порог мирры 100, батареи и модули выключены. `/myrrh 100` — задать порог мирры без окна.
- Настройки общие для всех персонажей: `data\Mods\Configs\MyrrhAlert`.
- Мана-батареи и модули памяти аддон находит по названию (внутренних имён в документации игры нет): предмет в сумке
  со словами «батарея» и «мана», ценность со словами «модуль» и «память». Правила — в начале `lua\Stock.lua`.
  Модули ищутся в общем списке ценностей, а если там их нет — по категориям ценностей.

```
lua\     скрипты (UTF-8): Util, Config, Stock (логика), UI, Main; LibDnD — чужая библиотека перетаскивания (Windows-1251)
gen\     assemble.py — собирает папку аддона; build.py — виджеты, тексты и текстуры окна (нужны numpy и Pillow)
test\    тесты на заглушках API игры: sh test/run.sh
release\ описание, краткое описание, список изменений, промо-картинки
tools\   strip_debug.py — вырезает отладку при сборке; promo\ — исходник промо-карточек (cards.html) и render.py,
         который снимает их в release\promo (нужен Chrome или Edge)
```

Сборка и установка из корня `C:\Development\Allods`: `python tools\build.py MyrrhAlert [--release]`.
