# MyrrhAlert

Аддон для Аллодов Онлайн: пока мирры у персонажа меньше порога, вверху экрана горит надпись «НЕДОСТАТОЧНО МИРРЫ».

- `/myrrh` — окно настроек: порог (по умолчанию 100, 0 — выключить) и текущее количество мирры. `/myrrh 100` — задать порог без окна.
- Настройки общие для всех персонажей: `data\Mods\Configs\MyrrhAlert`.

```
lua\     скрипты (UTF-8): Util, Config, Myrrh (логика), UI, Main; LibDnD — чужая библиотека перетаскивания (Windows-1251)
gen\     assemble.py — собирает папку аддона; build.py — виджеты, тексты и текстуры окна (нужны numpy и Pillow)
test\    тесты на заглушках API игры: sh test/run.sh
release\ описание, краткое описание, список изменений, промо-картинки
```

Сборка и установка из корня `C:\Development\Allods`: `python tools\build.py MyrrhAlert [--release]`.
