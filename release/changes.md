Кратко: Предупреждает, когда мирры меньше порога

Изменения 0.1.0:
- Первая версия: надпись «НЕДОСТАТОЧНО МИРРЫ» вверху экрана, пока мирры у персонажа меньше порога.
- Окно настроек по команде `/myrrh`: поле с порогом и текущее количество мирры. Порог 0 выключает предупреждение.
- Порог можно задать и сразу командой: `/myrrh 100`.
