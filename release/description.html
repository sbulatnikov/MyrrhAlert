MyrrhAlert 0.1.0

Автор: NoMercy

Пока мирры у персонажа меньше заданного порога, вверху экрана горит надпись «НЕДОСТАТОЧНО МИРРЫ». Как только мирры становится достаточно, надпись пропадает сама.

Настройка

Порог задаётся командой в чате и запоминается для всех персонажей:

КомандаЧто делает аддон
/myrrh 100ставит порог 100: надпись видна, пока мирры меньше 100
/myrrh 0выключает предупреждение
/myrrhпишет в чат текущий порог и сколько мирры сейчас

Пока порог не задан, он равен 100. Надпись не мешает кликам: они проходят сквозь неё.
