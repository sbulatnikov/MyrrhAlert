MyrrhAlert 0.1.0

Автор: NoMercy

Пока мирры у персонажа меньше заданного порога, вверху экрана горит надпись «НЕДОСТАТОЧНО МИРРЫ». Как только мирры становится достаточно, надпись пропадает сама.

Настройка

Команда /myrrh в чате открывает окно настроек. В нём — поле с порогом и текущее количество мирры. Введите число и нажмите Enter или «Применить»; Esc возвращает прежнее значение. Порог 0 выключает предупреждение.

Окно перетаскивается за шапку и запоминает своё место. Порог общий для всех персонажей; пока он не задан, он равен 100.

Порог можно задать и без окна: /myrrh 100.

Надпись не мешает кликам: они проходят сквозь неё.
